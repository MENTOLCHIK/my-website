Инструкции по настройке

Выберите вашу платформу и следуйте пошаговой инструкции

Настройка Telegram-бота

1. Запустите бота

Перейдите: @Pharifer_bot → /start → Пробная подписка

2. Основные команды бота
🎁 Пробная подписка — получить пробную подписку
⚙️ Конфигурация — отправляет конфигурацию
👤 Информация по подписке — срок действия подписки
📖 Инструкции — ссылка на этот сайт
💬 Присоединиться к беседе — чат с пользователями

Настройка на Android и iOS

| v2RayTun

1. Установите приложение
v2RayTun для Android v2RayTun для iOS
2. Получите конфигурацию

@Pharifer_bot → /start → 🎁 Пробная подписка

3. Импортируйте конфигурацию

Нажмите на "+" в правом верхнем углу

4. Импортируйте конфигурацию

Импорт из буфера обмена

5. Подключитесь

Включите VPN
( также советую изменить название конфигурации, нажав на иконку, отмеченную на скрине )

6. Меняете название

Меняем название и нажимаем на галочку в правом верхнем углу
( перед этим нужно отключить впн )

Настройка на Windows и macOS

| Clash Verge

1. Скачайте Clash Verge
Windows macOS
2. Добавьте новый профиль

Профили → Новый

3. Настройте тип профиля

Тип → Local

4. Вставка конфига

Выберите конфиг, полученный от бота

5. Настройка приложения

Настройки → Включите Режим TUN → Включите Системный прокси

6. Настройка приложения

Прокси → Выберите раздел правила

7. Выбор сервера

Раскрываем список серверов → выбираете один из доступных серверов

АнтиГлушилка — обход белых списков

Работает только на Android и iOS. Автоматически обходит DPI и белые списки.

| Happ

1. Установите приложение
Happ для Android Happ Plus для iOS
2. Добавьте конфигурацию

Из буфера обмена → Вставьте конфиг, полученный от администратора

3. Дальнейшее добавление конфигов

Нажмите на "+" в правом верхнем углу → Вставить из буфера обмена

4. Выберите сервер и подключитесь

Нажмите на название сервера для выбора и активируйте подключение

Включать только при активных белых списках! При обычном использовании интернета функция не нужна.
