Clash Verge - одно из самых лучших приложений, которое мы нашли для использования нашего VPN

Для Windows, а также для macOS

Открыть чат с ботом для получения конфига

Если вы ранее использовали старую версию Clash Verge, то тогда для начала вам нужно сделать следующие действия! ( показано на Windows, на macOS ничего делать не надо )

Компьютер\HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\clash_verge_service

Вот инструкция по настраиванию приложения для новых пользователей! ( показано на Windows, но на macOS нужно проделать те же действия )

Если вам все-таки осталось что-то непонятно, то не стесняйтесь писать ему! Он ответит и поможет вам с любым вопросом.
